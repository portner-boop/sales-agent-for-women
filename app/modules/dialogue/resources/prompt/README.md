# Промпт Марко

Файлы с номерами склеиваются в этом порядке в каждый запрос (общая часть):

1. `01_identity.md` — кто он, ответ «я Марко», контакты и встречи.
2. `02_style.md` — как он пишет: длина, форма, флирт, запреты.
3. `03_examples.md` — пары «плохо/хорошо», утверждённые клиентом.
4. `04_life_and_memory.md` — Сплит, время, чем занят, память о ней.
5. `05_rules.md` — её ограничения, платформа, последний ответ.
6. `06_output.md` — формат JSON.

Затем добавляется одна часть по ситуации: `turn.md` на новое сообщение, `timer.md` + `timer_first.md` или `timer_second.md` для follow-up.

Этот README в промпт не попадает. После правки перезапустите бота и прогоните приёмку:
`uv run python -m app.modules.dialogue.acceptance run --report reports/acceptance/<имя>.json --summary reports/acceptance/<имя>.md`
