При прерывании того же прогона добавить `--resume`: успешно завершённые случаи сохраняются, ошибки повторяются. Resume проверяет совпадение хешей каталога и реализации. Старые `.3`/`.4` отчёты до последней правки не подходят для resume текущего кода. API 401/402/403 останавливает дальнейшие удалённые запросы; частичная переписка сохраняется. Для прежнего запуска до этой защиты часть незавершённых случаев сохранила только тип ошибки.

## Метрики

`agent_runs.manifest_json.policy`: версия, checksum, ID правил, причины выбора, бюджет. `metrics_json.llm_events`: этап, входные/выходные токены, ожидание семафора, модель, ошибки и повторы. `behappy-manage metrics` после установки покажет фазовые p50/p95 и агрегаты последних 1000 попыток.

`queued_seconds` включает ожидание lock; `lock_seconds` — его отдельная составляющая. `context_seconds` включает подбор, `selection_seconds` показывает его часть. Время repair включает проверку исправления; отдельная validation-метрика пересекается с ним. Эти величины нельзя складывать как непересекающиеся интервалы. `pacing_planned_seconds` — запланированные паузы, транспорт измеряется монотонными часами отдельно. В сравнительном скрипте действительное время QMD хранится в selections и retrieval, а runtime selection_seconds относится к исходной Python-сборке контекста.
